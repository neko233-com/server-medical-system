# 功能清单 · FEATURES

系统覆盖医院**门诊 → 住院准备 → 药房 → 收费核算 → 管理层决策**的全链路场景，全部集成在 Web 端。

---

## 1. 患者管理

| 能力 | 说明 |
| --- | --- |
| 建档 | 姓名、性别、出生日期、电话、身份证、**血型**、**过敏史**（过敏史在开方时作为安全提示依据） |
| 检索 | 关键字搜索 + 分页 |
| 详情 | 单个患者的完整时间线：历次病例 + 历次处方 |
| 权限 | `patient:read` / `patient:write` |

## 2. 接诊与病例

| 能力 | 说明 |
| --- | --- |
| 开诊 | 选择患者 → 填写主诉、现病史、既往史、诊断、医嘱 |
| 关联房间 | 病例自动记录**门诊房间号**与房间 ID，用于房间占用统计 |
| 时间线 | 按患者维度聚合全部就诊记录 |
| 权限 | `case:read` / `case:write` |

## 3. 处方开方

| 能力 | 说明 |
| --- | --- |
| 开方 | 从药品库选药，自动按单价 × 数量计算总金额 |
| 打印 | 跳转全屏打印视图（`window.print`），**同步记录打印审计**（含医生、房间、打印机） |
| 发药 | 状态流转 `draft → issued → dispensed` |
| 权限 | `prescription:read` / `prescription:create` / `prescription:dispense` |

## 4. 药品库（常用药全量 + 可扩展）

| 能力 | 说明 |
| --- | --- |
| 内置品种 | 60+ 常用药，覆盖抗生素、解热镇痛、心血管、消化、呼吸、内分泌、神经、抗过敏、维生素、外用、中成药、五官等，**中英双语名称** |
| 后台维护 | 新增 / 编辑 / 停用 / **配置价格** |
| **库存管理** | 字段 `stock_qty`（现有库存）与 `reorder_level`（补货警戒线）；低于警戒线自动进入运营看板缺货预警 |
| 权限 | `medicine:read` / `medicine:manage`，库存 `inventory:read` / `inventory:manage` |

## 5. 门诊房间管理

| 能力 | 说明 |
| --- | --- |
| 房间台账 | 房间号、中英文名称、类型（诊室 / 手术室 / 放射科 / 急诊）、科室、楼层、状态 |
| 绑定医生 | 房间可绑定出诊医生（`PUT /rooms/:id/doctor`） |
| 绑定打印机 | 房间可指定默认打印机，作为打印路由的二级依据 |
| 权限 | `room:read` / `room:manage` |

## 6. 打印与打印路由

打印机解析采用**三级优先级**，保证单据永远发到正确的设备：

```
1. 绑定医生   —— 当前医生有专属打印机则优先
2. 房间默认   —— 否则取所在门诊房间绑定的打印机
3. 全局默认   —— 再否则取标记为默认的全局打印机
```

| 能力 | 说明 |
| --- | --- |
| 打印机台账 | 名称、类型、连接方式、IP、端口、状态 |
| 自动解析 | `GET /printers/resolve`，可直接返回应使用的打印机 |
| 打印审计 | 每次打印生成 `PrintJob` 记录（打印机、医生、房间、患者、文档类型、摘要） |
| 权限 | `printer:read` / `printer:manage` |

## 7. 手术管理

| 能力 | 说明 |
| --- | --- |
| 排期 | 手术申请 → 主刀 / 助手 / 麻醉师 / 手术室 / 麻醉方式 / 术前诊断 |
| 生命周期 | `planned → in_progress → done`（自动写入 `started_at` / `ended_at` 时间戳）或 `cancelled` |
| 术后记录 | 术后诊断、术中发现、手术步骤、并发症、时长 |
| 编号 | 自动生成手术号（如 `OP20261101-06XXXX`） |
| 权限 | `surgery:read` / `surgery:manage` |

## 8. 影像中心（CT / X 光 / MRI / 超声）

| 能力 | 说明 |
| --- | --- |
| 检查登记 | 患者、 modality（CT/X-Ray/MRI/US…）、部位、临床指征 |
| 样片上传 | 多张图片，支持 ≤25MB/张，限制 `image/*` 与 `application/dicom` |
| **安全回显** | 样片经**带鉴权**接口返回；因 `<img>` 无法携带 Bearer，前端用 `AuthImage` 组件以 blob 方式加载 |
| 报告 | 所见（Findings）+ 印象（Impression），状态 `ordered → done → reported`，签署人记录 |
| 权限 | `imaging:read` / `imaging:upload` / `imaging:report` |

## 9. 🧮 医院运营总览（管理员后台运营）

面向院领导与管理者的**全院量化核算**，详见 [RBAC 说明](./RBAC.md)中的 `report:read`。

| 模块 | 指标 |
| --- | --- |
| 核心 KPI | 累计患者、在岗医生、今日门诊量、今日处方数 |
| 收入核算 | 今日收入、本月收入（以处方金额为准，两位小数精确核算） |
| 待办积压 | 待排手术数、待写影像报告数 |
| 库存预警 | 低于警戒线的药品品种数 |
| 趋势图 | 近 N 天（7/14/30 可切）逐日门诊量 + 收入，缺失日期自动补零以保证图表连续 |
| 科室效能 | 各科室医生数、门诊量、收入 |
| 医生效能 | 各医生门诊量、处方数、收入排行 |
| 资源状态 | 房间实时占用（今日已接诊 / 空闲）、打印机清单、最近打印任务 |

端点：`/operations/overview`、`/operations/trend`、`/operations/departments`、`/operations/doctors`、`/operations/status`。

> 实现要点：为兼容三种数据库，**不使用任何方言日期函数**，改为在 Go 侧计算时间边界并按天分桶，行为完全一致。

## 10. 全局化 i18n

- 界面默认**简体中文**，一键切换**英文**；新增语言只需增加一个语言包文件。
- 药品/房间名称内建中英双语字段，切换语言即时生效。
- **服务端消息**（错误提示、校验消息）同样支持 `Accept-Language` 多语言，前后端语言口径统一。

## 11. RBAC 权限体系

7 种内置角色 + 26 项细粒度权限，支持角色授权与**用户级覆盖**（授予 / 撤销），接口级强制校验。详见 [RBAC.md](./RBAC.md)。

## 🎯 典型业务走查（一个上午的真实流程）

```
①  receptionist 挂号收费 ──► 建档/检索患者
②  doctor       接诊   ──► 选择门诊房间 201 → 写病例 → 开处方
③  doctor       打印   ──► 自动解析打印机（医生绑定→房间默认→全局默认）→ 生成 PrintJob 审计
④  radiologist  影像   ──► 开检查单 → 上传 CT 样片 → 写报告
⑤  surgeon      手术   ──► 排期 OR1 → 术中/术后记录
⑥  pharmacist   发药   ──► 处方 dispensed → 库存扣减/补货警戒
⑦  admin        运营   ──► 查看全院门诊量、收入、科室效能、缺货预警
```
